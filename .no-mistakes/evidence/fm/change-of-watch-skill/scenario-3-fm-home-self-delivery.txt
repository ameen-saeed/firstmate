# Scenario 3 (adversarial): an unwrapped note run self-delivers into the sender's own home
# FM_HOME selects whose state/ and data/ receive the note. The skill pins it to the
# receiver; with it unset fm-inbox.sh falls back to its own script root - the sender's home.

# (a) FM_HOME unset, using a disposable byte-identical installation of the product so the
#     fallback root is disposable (this worktree is never written to):
$ (cd /var/folders/29/jjv5r2_x2jv3fm_3xv78zkdr0000gn/T//cow-fmhome.8SNMGl/disposable-mac-home && bin/fm-inbox.sh note accepted atlas)
queued 1792020265-uF8fAb
  accepted atlas
  firstmate will pick this up at its next check.
[exit=0]
$ ls $DP/state/inbox        # delivered to the runner's OWN home, not the receiver's
1792020265-uF8fAb.note
$ ls $PC/state/inbox 2>&1  # intended receiver got nothing
ls: /var/folders/29/jjv5r2_x2jv3fm_3xv78zkdr0000gn/T//cow-fmhome.8SNMGl/pc-home/state/inbox: No such file or directory

# (b) FM_HOME pointed at the SENDER's own home (the classic copy-paste mistake):
$ (cd /Users/ameen/.no-mistakes/worktrees/263a936a3c0b/01M4YAZPDQGHZSTJCMD0DANTVF && env FM_HOME=/var/folders/29/jjv5r2_x2jv3fm_3xv78zkdr0000gn/T//cow-fmhome.8SNMGl/mac-home bin/fm-inbox.sh note accepted atlas)
queued 1792020265-Cp8Pok
  accepted atlas
  firstmate will pick this up at its next check.
[exit=0]
$ ls $MAC/state/inbox       # note is in the SENDER's inbox
1792020265-Cp8Pok.note
$ ls $PC/state/inbox 2>&1  # receiver still got nothing
ls: /var/folders/29/jjv5r2_x2jv3fm_3xv78zkdr0000gn/T//cow-fmhome.8SNMGl/pc-home/state/inbox: No such file or directory

# (c) Contrast - the documented wrapper's explicit FM_HOME=<receiver> pin:
$ (cd /Users/ameen/.no-mistakes/worktrees/263a936a3c0b/01M4YAZPDQGHZSTJCMD0DANTVF && env FM_HOME=/var/folders/29/jjv5r2_x2jv3fm_3xv78zkdr0000gn/T//cow-fmhome.8SNMGl/pc-home bin/fm-inbox.sh note accepted atlas-pinned)
queued 1792020265-cfRzyS
  accepted atlas-pinned
  firstmate will pick this up at its next check.
[exit=0]

$ ls $MAC/state/inbox       # sender inbox untouched by the pinned send
